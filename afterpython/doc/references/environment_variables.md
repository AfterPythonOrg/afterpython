# Environment Variables

## `AP_AUTO_SYNC`
> Default: `0`. If set to `1`, automatically syncs configuration from `pyproject.toml` and `afterpython.toml` to `authors.yml` and `myst.yml` files.

---
## `AP_MOLAB_BADGE`
> Default: `0`. If set to `1`, adds a molab badge to the home page built from `README.py` in static mode. Content notebooks opt in per notebook with `molab_badge: true` in their frontmatter instead.
